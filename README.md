# TankShot

TankShot is a browser tank game built with HTML, CSS, and JavaScript.

## Latest update — V17

- Adds a bottom-of-screen ammo selector that shows every projectile, marks locked shells, and lets players select owned ammo by clicking or pressing 1–9. Q still cycles unlocked ammo.
- Organizes the Armory into three tiers. Tier II opens after completing mission 5; Tier III opens after mission 15. Individual shell unlocks still cost coins, with elite tank defeats granting their special ammo rewards.
- High Scores remains temporarily removed while a secure JSONBin relay is unavailable.

Host the repository with GitHub Pages and embed its `index.html` page in your site.
