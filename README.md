# TankShot

TankShot is a browser tank game built with HTML, CSS, and JavaScript.

## Latest update — V26

- Shows whether each high score submission actually saved to JSONBin and displays the API error if it fails.
- Keeps score submissions in order and shows only server-provided scores when the connection is live, preventing unsaved device data from appearing as online scores.

High Scores use JSONBin with the restricted `X-Access-Key` configured in `leaderboard-config.js`. Host the repository with GitHub Pages and embed its `index.html` page in your site.
