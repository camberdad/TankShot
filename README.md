# TankShot

TankShot is a browser tank game built with HTML, CSS, and JavaScript.

## Latest update — V25

- Requires new players to choose a 3–16 character username that is unique on the live high score board before starting. Returning players can select their saved username.
- Turns camera shake off by default, including for existing local profiles; it can still be enabled in Settings.

High Scores use JSONBin with the restricted `X-Access-Key` configured in `leaderboard-config.js`. Host the repository with GitHub Pages and embed its `index.html` page in your site.
