# TankShot

TankShot is a browser tank game built with HTML, CSS, and JavaScript.

## Latest update — V23

- Removes right-click as a Mine shortcut; Mines are placed with E, Shift, or the on-screen Mine button.

High Scores use JSONBin with a restricted `X-Access-Key` configured in `leaderboard-config.js`. Host the repository with GitHub Pages and embed its `index.html` page in your site.
