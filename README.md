# TankShot

TankShot is a browser tank game built with HTML, CSS, and JavaScript.

## Latest update — V20

- Makes missions slightly easier to clear by reducing enemy counts on generated missions and slightly slowing enemy aim and firing on Normal difficulty.
- Increases tank defeat rewards from 25 to 40 coins and coin crate rewards from 35 to 50 coins, so armory items and upgrades are easier to earn.
- Keeps Hard mode challenging and Easy mode more forgiving, with small balance adjustments to both.

High Scores remain temporarily removed while a secure JSONBin relay is unavailable. Host the repository with GitHub Pages and embed its `index.html` page in your site.
