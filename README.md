# TankShot

TankShot is a browser tank game built with HTML, CSS, and JavaScript.

## Latest update — V19

- Keeps the nine ammunition types visually distinct, with upgrade-scaled projectiles and impact effects.
- Makes the gameplay ammunition selector compact and translucent.
- Fixes the update loop by refreshing the updater cache tag and preventing repeated automatic reload attempts when a stale browser build persists.
