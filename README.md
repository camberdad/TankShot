# TankShot

TankShot is a browser tank game built with HTML, CSS, and JavaScript.

## Latest update — V18

- Gives all nine ammo types distinct projectile silhouettes, colors, trails, and impact effects.
- Adds five upgrade levels per unlocked ammo type. Upgrades increase projectile speed and improve each shell's defining effect, while brighter colors, larger projectiles, stronger trails, and more intense impacts show the upgrade level.
- Adds shrapnel fragments and cluster submunitions that scale with upgrades.
- Makes the gameplay ammo selector smaller and more translucent.

High Scores remain temporarily removed while a secure JSONBin relay is unavailable. Host the repository with GitHub Pages and embed its `index.html` page in your site.
